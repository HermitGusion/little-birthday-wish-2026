# 生日祝福网页

零依赖的静态网页：同一时刻只展示一根数字蜡烛，按 3 → 2 → 1 倒数；48 张写有祝福的便利贴逐张围出心形（没有心形底线）；随后在近 200 段祝福文字构成的底图上，逐笔描出线条蛋糕。动画灵感来自同目录的两个参考视频；心形便签沿用了提供的 Python 爱心参数方程。原始视频和素材没有上传。

## 打开与分享

双击 `index.html` 可以本地预览。跨网络分享请使用 GitHub Pages 提供的公开 HTTPS 地址；不能把 `file://` 或 `localhost` 地址发给别的手机。

链接支持可选参数，例如 `?name=小雨&wish=愿你每天都闪闪发光`。不要在公开链接里填写私人信息。也可以直接修改 `script.js` 顶部的 `defaultWish` 和 `wishes`，以及 `index.html` 的默认称呼。

打开页面约 1.5 秒后自动开始，也可以提前点击按钮开始。便签阶段点击任意一张可以停留阅读完整祝福，再点“继续拆开蛋糕惊喜”进入蛋糕；不点击则自动前进。还可以跳过、重播、复制链接。系统开启“减少动态效果”时保留三个场景、减少移动效果。页面没有第三方 JS、图片或音频请求，离线预览也可运行。

## 部署

GitHub 仓库 Settings → Pages → Build and deployment → Deploy from a branch，选择 `main` 和 `/ (root)`。部署后等候公开地址出现，再用手机的移动网络打开该 HTTPS 地址验证。
