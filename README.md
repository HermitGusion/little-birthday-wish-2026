# 生日祝福网页

零依赖的静态网页：深色星光背景里，数字本身就是蜡烛，按 3 → 2 → 1 单独倒数；随后出现“准备好了吗”过场，三种软萌字体的生日快乐在背景中流动；接着没有编号的粉彩纸卡沿心形逐张层叠，停留在中央生日卡；心形页用开源手写体“志莽行”的生日快乐大字作自适应底图；最后转入深色画面，在占满屏幕的完整祝福句底图上逐笔描出暖金色线条蛋糕。节奏和配色参考同目录两个视频，心形位置沿用了提供的 Python 爱心参数方程。原始视频和素材没有上传。

## 打开与分享

双击 `index.html` 可以本地预览。跨网络分享请使用 GitHub Pages 提供的公开 HTTPS 地址；不能把 `file://` 或 `localhost` 地址发给别的手机。

链接支持可选参数，例如 `?name=小雨&wish=愿你每天都闪闪发光`。不要在公开链接里填写私人信息。也可以直接修改 `script.js` 顶部的 `defaultWish` 和 `wishes`，以及 `index.html` 的默认称呼。

打开页面约 1.5 秒后自动开始，也可以提前点击按钮开始。便签阶段点击任意一张会暂停自动翻页，并在心形中央阅读完整祝福；再点圆形箭头按钮进入蛋糕，不点击则自动前进。继续与重播均为纯图标按钮，并保留无障碍名称；页面不显示复制链接按钮。祝福文字使用随页嵌入的站酷快乐体子集，授权为 SIL Open Font License 1.1，完整版权与授权文本位于 cartoon-font.css 文件头。新增手写体与软萌展示体同样随页嵌入，授权文本位于 scene-fonts.css 文件头。系统开启“减少动态效果”时保留四个场景、减少移动效果。页面没有第三方 JS、图片或音频请求，离线预览也可运行。

## 部署

GitHub 仓库 Settings → Pages → Build and deployment → Deploy from a branch，选择 `main` 和 `/ (root)`。部署后等候公开地址出现，再用手机的移动网络打开该 HTTPS 地址验证。
